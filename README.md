# Índice de Riesgo de Calidad del Agua

Aplicación web desarrollada en Python para estimar el nivel de riesgo de calidad del agua utilizando Machine Learning.

## Probar aplicación

[Ir a la aplicación](https://indicederiesgocalidadagua.onrender.com/)

## Tecnologías

- Python
- Pandas
- Scikit-learn
- Gradient Boosting
- Flask
- HTML/CSS

## Parámetros utilizados

- pH
- Turbiedad
- Color
- Coliformes totales
- Coliformes fecales

## Niveles de riesgo

- Sin riesgo
- Riesgo bajo
- Riesgo medio
- Riesgo alto
- Inviable sanitariamente
