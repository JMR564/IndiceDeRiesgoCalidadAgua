# Índice de Riesgo de Calidad del Agua

Aplicación desarrollada en Python para estimar el nivel de riesgo de calidad del agua a partir de diferentes parámetros fisicoquímicos y microbiológicos.

El proyecto utiliza un modelo de Machine Learning para clasificar los resultados en diferentes niveles de riesgo.

## Tecnologías

* Python
* Pandas
* Scikit-learn
* Gradient Boosting
* Flask
* HTML/CSS

## Parámetros utilizados

* pH
* Turbiedad
* Color
* Coliformes totales
* Coliformes fecales

## Niveles de riesgo

* Sin riesgo
* Riesgo bajo
* Riesgo medio
* Riesgo alto
* Riesgo inviable sanitariamente

## Ejecución

Instalar las dependencias:

```bash
pip install -r requirements.txt
```

Ejecutar la aplicación:

```bash
python app.py
```

Luego ingresar a:

```text
http://127.0.0.1:5000
```
